## 📌 Sobre o Projeto

Este projeto apresenta um dashboard desenvolvido no **Power BI** para acompanhamento do desempenho de vendas. O painel foi criado para fornecer uma visão estratégica dos principais indicadores comerciais, permitindo analisar faturamento, pedidos, ticket médio, desempenho dos vendedores e distribuição geográfica das vendas.

---

## 🎯 Objetivo

Desenvolver um dashboard executivo que possibilite acompanhar os principais indicadores da área comercial, auxiliando gestores na avaliação do desempenho das equipes, das lojas e da evolução das vendas ao longo do tempo.

---

## 🛠️ Tecnologias Utilizadas

- Power BI Desktop
- Power Query
- DAX
- Modelagem de Dados
- Excel

---

## 📂 Etapas do Projeto

### 📥 Coleta dos Dados

- Importação da base de vendas.
- Organização das informações comerciais.
- Validação da consistência dos dados.

### 🔄 Tratamento dos Dados

Durante o processo de ETL foram realizadas atividades como:

- Remoção de registros duplicados;
- Tratamento de valores nulos;
- Padronização das informações;
- Ajuste dos tipos de dados;
- Organização das tabelas para análise.

### 🧩 Modelagem dos Dados

Foi desenvolvido um modelo de dados com relacionamentos entre tabelas para otimizar o desempenho das consultas e das visualizações.

---

## 📐 Indicadores Desenvolvidos

O dashboard apresenta indicadores como:

- 💰 Faturamento Total
- 📦 Total de Pedidos
- 💳 Ticket Médio
- 👤 Desempenho por Vendedor
- 🏪 Faturamento por Loja
- 📅 Evolução do Faturamento ao Longo do Tempo

---

## 📊 Funcionalidades do Dashboard

O painel permite analisar:

- Faturamento total;
- Quantidade de pedidos;
- Ticket médio;
- Evolução das vendas por período;
- Desempenho individual dos vendedores;
- Distribuição geográfica das lojas;
- Comparativo de faturamento entre lojas;
- Filtro para seleção de vendedores.

---

## 📈 Principais Insights

Com este dashboard é possível:

- Identificar os vendedores com melhor desempenho.
- Comparar o faturamento entre lojas.
- Monitorar a evolução das vendas ao longo do tempo.
- Avaliar o ticket médio das vendas.
- Analisar a distribuição geográfica dos resultados comerciais.
- Apoiar decisões estratégicas para aumento das vendas.
